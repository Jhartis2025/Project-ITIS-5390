HOW TO RUN IT
  1. Download the .zip file and unzip it (right-click > Extract All on
     Windows, or double-click it on Mac).
  2. Open the "websiteproject" folder.
  3. Double-click homepage.html. It opens in your web browser.
     Google Chrome is recommended.
  4. To go straight to the form, double-click account.html, or click
     "Account" in the top navigation (or in the mobile menu).
  5. Stay connected to the internet so product photos and the Inter
     font load. Without internet the pages still work; photos show
     "Image unavailable" instead.

OPTIONAL: RUN IT ON A LOCAL SERVER
  If your browser blocks saving settings for files opened directly
  (dark mode, the bag or your name resetting between pages):
  1. Open a terminal in the "websiteproject" folder.
  2. Run:  python -m http.server 8000
     (on some Macs use:  python3 -m http.server 8000)
  3. Go to http://localhost:8000/homepage.html in your browser.

HOW TO TEST MOBILE AND DESKTOP
  1. In Chrome, right-click the page and choose Inspect.
  2. Click the phone/tablet icon (Toggle device toolbar).
  3. Set the width to 375 for mobile, then 1280 for desktop.

ASSIGNMENT 13: ACCESSIBILITY + DARK MODE
------------------------------------------------------------
1. DARK MODE SWITCH
   - Where: top right of every page on desktop; inside the menu
     (hamburger) on phones.
   - It's an on/off switch that shows the CURRENT mode: "Dark mode
     [switch] Off" in light mode, knob slides right + "On" in dark
     mode. (Before, the button said "Light mode" while dark mode was
     on, which read backwards.) Screen readers hear "Dark mode,
     switch, on/off".
   - Works on every page + every component: header, menus, search
     suggestions, product cards, bag panel, quick add + size guide
     pop-ups, the account form, error/success states.
   - Your choice is saved, so it stays on when you change pages or
     reload. If you have never picked, the site follows your
     device's light/dark setting.
   - The dark palette is designed, not inverted: #121212 background,
     lighter #202020/#333333 surfaces for bars + photo frames, softer
     error/success colors chosen for dark backgrounds.

3. FOCUS STATES (keyboard users)
   - Every link, button, input, card + checkbox shows a thick outline
     with a halo when you Tab to it, visible on white, black and on
     photos. The search box + form fields used to remove the outline
     (outline:none) and use a faint ring; that's fixed.
   - New "Skip to main content" link: press Tab once on any page.

4. TEXT SIZE + 200% ZOOM
   - Every font size is now in rem (no px font sizes left), touch
     targets are 2.75rem, and the layout breakpoints are in em, so
     everything grows when someone zooms or sets a bigger default
     font in their browser.
   - Tested on all 4 pages in light + dark at:
       200% page zoom on desktop (1280px -> 640px)
       200% page zoom on a phone (320px wide)
       200% text size on desktop (1280px) + phone (375px)
     Result: no horizontal scrolling, nothing cut off or overlapping.
   - Fixes from that testing: the desktop header wraps onto a second
     row instead of pushing "Bag" off the screen; the search box width
     is in rem; the phone hero grows taller so the Shop button never
     covers the Pause/dots row.

   HOW TO CHECK IT YOURSELF
   - Zoom: press Ctrl and + (Cmd and + on Mac) until it says 200%.
   - Bigger text: Chrome Settings > Appearance > Font size > Very large.
   - Contrast: Chrome DevTools > Lighthouse > Accessibility, or paste
     the colors above into the WebAIM Contrast Checker.
   - Keyboard: press Tab to move through the page, Enter/Space to use.

THE FORM: CREATE ACCOUNT (account.html)
------------------------------------------------------------
Fields: Name, Email, Phone (optional), Password, Confirm
password, Terms checkbox (+ an optional newsletter checkbox).

WHEN IT CHECKS (helpful, not hostile)
  - Typing in a field you haven't left yet: no red errors on the
    first keystroke; it turns green as soon as it's valid.
  - Leaving a field: it's fully checked and any error shows.
  - After that, it re-checks on every keystroke, so the error goes
    away the moment you fix it.
  - The password checklist + strength bar update live as you type.
  - Submit checks everything once more and jumps to the first
    problem. There are no alert boxes.

HOW ERRORS + SUCCESS LOOK
  - Error: red border, red "!" icon in the field, red message right
    under the field. Unmet password rules turn red.
  - Success: green border, green check in the field, a short
    "Looks good" style message.
  - Space for messages is reserved, so the form doesn't jump around
    when a message appears.
